## 소개

**hong-ik**은 한글을 기반으로 설계된 자체 프로그래밍 언어 프로젝트입니다. C++로 작성되었으며 바이트코드 VM(기본)과 트리워킹 인터프리터(`--eval`)를 모두 지원합니다.

## 설치 및 실행 방법

### 필요한 환경
- C++26을 지원하는 최신 컴파일러 (네이티브 빌드는 `CMAKE_CXX_STANDARD 26`)
- [CMake](https://cmake.org/) 3.28 이상
- (선택) WASM 빌드: [Emscripten](https://emscripten.org/) — WASM 타깃은 C++20으로 컴파일됩니다 (`scripts/build-wasm.sh`)

### 빌드
```bash
cmake -B cmake-build-debug
cmake --build cmake-build-debug
```

### 테스트
```bash
ctest --test-dir cmake-build-debug
```

### 프로그램 실행
```bash
# 파일 실행 (기본: 바이트코드 VM)
./cmake-build-debug/HongIk filename.hik

# REPL 모드
./cmake-build-debug/HongIk

# 트리워킹 인터프리터로 실행
./cmake-build-debug/HongIk --eval filename.hik

# 정적 타입 검사 모드 (off|warn|strict, 기본 warn)
./cmake-build-debug/HongIk --type-check=strict filename.hik
```

`--type-check=warn`(기본)은 실행 전에 찾은 타입 오류를 `type-warning[...]`으로 출력하고 그대로 실행합니다. `strict`는 `type-error[...]`로 출력하고 실행하지 않으며, `off`는 검사를 건너뜁니다.

## 언어 문법

### 변수 선언
```
정수 x = 10
실수 pi = 3.14
문자 이름 = "홍길동"
논리 참 = true
배열 목록 = [1, 2, 3]
사전 정보 = {"이름": "홍길동", "나이": "25"}
```

선언한 타입과 값의 타입이 맞아야 합니다 (암묵 승격 없음 — `실수 r = 1`은 에러, `실수 r = 1.0`을 사용).

### Null 타입과 Optional
`없음`은 null 값입니다. 일반 타입 변수에는 `없음`을 넣을 수 없고, 타입 뒤에 `?`를 붙인 Optional 타입만 `없음`을 가질 수 있습니다.
```
정수? x = 없음
x == 없음    // true
x = 3        // Optional 변수에는 일반 값도 대입 가능

// 정수 y = 없음   // 에러: 선택적 타입이 아닌 변수에 '없음'을 대입할 수 없습니다.
```

### 문자열 보간
```
문자 이름 = "홍길동"
문자 인사 = "안녕 {이름}님"    // "안녕 홍길동님"
```

문자열 리터럴 안의 `{...}`는 항상 보간으로 해석됩니다. JSON 객체처럼 중괄호가 든 문자열이 필요하면 `"{" + "\"a\": 1}"`처럼 나눠 이어 붙이세요.

### 조건문
```
정수 x = 7
만약 x > 5 라면:
    출력("크다")
아니면:
    출력("작다")
```

### 반복문 (while)
```
정수 i = 0
반복 i < 10 동안:
    i += 1
```

### 범위 반복문 (for-range)
```
반복 정수 i = 0 부터 10 까지:    // 0 ~ 9 (끝 값 미포함)
    출력(i)
```

### ForEach 반복문
```
각각 정수 원소 [1, 2, 3] 에서:
    출력(원소)
```

### 중단 / 계속 (break / continue)
```
정수 i = 0
반복 i < 10 동안:
    i += 1
    만약 i == 2 라면:
        계속          // 2는 건너뜀
    만약 i == 5 라면:
        중단          // 5에서 반복 종료
    출력(i)           // 1, 3, 4
```

### 함수 선언 및 호출
```
함수 더하기(정수 a, 정수 b) -> 정수:
    리턴 a + b

더하기(3, 7)    // 10
```

### 기본 매개변수
```
함수 인사(문자 이름, 문자 접미사 = "님") -> 문자:
    리턴 이름 + 접미사

인사("홍길동")        // "홍길동님"
인사("홍길동", "씨")  // "홍길동씨"
```

### 제너레이터 (생산)
함수 본문에서 `생산`으로 값을 하나씩 내보내고, `각각`으로 순회합니다.
```
함수 세기(정수 끝) -> 정수:
    정수 i = 0
    반복 i < 끝 동안:
        생산 i
        i += 1

각각 정수 n 세기(3) 에서:
    출력(n)    // 0, 1, 2
```
> 현재 정적 타입 검사기는 제너레이터 순회에 경고(TC302)를 내지만 실행에는 영향이 없습니다.

### 고차 함수 (Lambda/Higher-order)
`매핑`, `걸러내기`, `줄이기`는 현재 **트리워킹 인터프리터(`--eval`)에서만** 동작합니다. 기본 VM에서는 "존재하지 않는 식별자" 에러가 납니다.
```
함수 두배(정수 x) -> 정수:
    리턴 x * 2

함수 양수(정수 x) -> 논리:
    리턴 x > 0

함수 합(정수 누적, 정수 x) -> 정수:
    리턴 누적 + x

매핑([1, 2, 3], 두배)         // [2, 4, 6]
걸러내기([1, -2, 3], 양수)    // [1, 3]
줄이기([1, 2, 3], 합, 0)      // 6
```

### 비교/매칭 (Match/Switch)
```
정수 x = 2
비교 x:
    경우 1:
        출력("일")
    경우 2:
        출력("이")
    기본:
        출력("기타")
```

`경우 시작~끝:` 형태로 범위(양 끝 포함)를 매칭할 수 있습니다.
```
정수 점수 = 85
비교 점수:
    경우 90~100:
        출력("A")
    경우 80~89:
        출력("B")    // 출력됨
    기본:
        출력("F")
```

### 튜플
```
(1, 2, 3)[0]    // 1
```

### 클래스 / OOP
```
클래스 동물:
    문자 이름
    정수 나이
    생성(문자 이름, 정수 나이):
        자기.이름 = 이름
        자기.나이 = 나이
    함수 소개() -> 문자:
        리턴 자기.이름

동물 강아지 = 동물("뽀삐", 3)
강아지.이름      // "뽀삐"
강아지.소개()    // "뽀삐"
```

### 상속
위 `동물` 클래스에 이어서:
```
클래스 강아지 < 동물:
    함수 소리() -> 문자:
        리턴 "멍멍"

강아지 뽀삐 = 강아지("뽀삐", 3)
뽀삐.소개()    // 부모 메서드 호출 가능
뽀삐.소리()    // "멍멍"
```

메서드 안에서 `부모.메서드()`로 부모 클래스의 메서드를 호출할 수 있습니다. 현재 **트리워킹 인터프리터(`--eval`)에서만** 동작하며, 기본 VM에서는 "존재하지 않는 식별자" 에러가 납니다.
```
클래스 동물:
    문자 이름
    생성(문자 이름):
        자기.이름 = 이름
    함수 소개() -> 문자:
        리턴 "저는 " + 자기.이름

클래스 강아지 < 동물:
    함수 소개() -> 문자:
        리턴 부모.소개() + " (강아지)"

강아지 뽀삐 = 강아지("뽀삐")
뽀삐.소개()    // "저는 뽀삐 (강아지)"
```

### 예외 처리
```
시도:
    정수 x = 10 / 0
실패 오류:
    출력(오류)
```

### 모듈 가져오기
```
가져오기 "파일명.hik"
```

### 음수 인덱싱
```
배열 목록 = [10, 20, 30]
목록[-1]    // 30
목록[-2]    // 20
```

### 증감 연산자
```
정수 x = 5
x++    // 6
x--    // 5
```

### 거듭제곱 연산자
```
2 ** 10    // 1024
2 ** 100   // 결과가 정수 범위를 넘으면 실수로 바뀜 (1267650600228229401496703205376.0)
```

`+`, `-`, `*` 등 다른 정수 연산은 결과가 64비트 정수 범위를 넘으면 런타임 에러("정수 연산 결과가 범위를 넘었습니다.")가 납니다.

### 논리 / 비트 연산자
```
true && false    // false
true || false    // true
!true            // false
6 & 3            // 2 (비트 AND)
6 | 3            // 7 (비트 OR)
```

> `~`는 비트 NOT이 아니라 `비교`문의 범위 패턴(`경우 1~5:`)에만 쓰입니다. `...`은 렉서가 토큰으로 인식하지만 가변 인자 문법은 아직 구현되어 있지 않습니다.

## 내장 함수 (45개 + 고차 함수 3개)

일반 내장 함수 45개(`object/builtin_registry.cpp`)와, 인터프리터가 별도로 처리하는 고차 함수 3개(`매핑`, `걸러내기`, `줄이기` — 현재 `--eval` 전용)가 있습니다. 레지스트리에는 `반복`(문자열 반복)도 등록되어 있지만 `반복`이 반복문 키워드라서 호출할 수 없으므로 개수에서 뺐습니다.

|------|------|------|
| `출력(값)` | 콘솔 출력 | `출력("안녕")` |
| `길이(값)` | 문자열/배열/사전 길이 | `길이("abc")` -> 3 |
| `추가(배열, 값)` | 배열에 원소 추가 | `추가(목록, 4)` |
| `타입(값)` | 타입 문자열 반환 | `타입(42)` -> "정수" |
| `정수변환(값)` | 정수로 변환 | `정수변환("42")` -> 42 |
| `실수변환(값)` | 실수로 변환 | `실수변환("3.14")` -> 3.14 |
| `문자변환(값)` | 문자열로 변환 | `문자변환(42)` -> "42" |
| `입력(프롬프트)` | 사용자 입력 | `입력("이름: ")` |
| `키목록(사전)` | 사전의 키 배열 | `키목록(정보)` |
| `포함(컬렉션, 값)` | 포함 여부 확인 | `포함("hello", "ell")` -> true |
| `설정(사전, 키, 값)` | 사전에 값 설정 | `설정(정보, "키", "값")` |
| `삭제(컬렉션, 키/인덱스)` | 원소 삭제 | `삭제(목록, 0)` |

| `부분문자(문자열, 시작, 끝)` | 부분 문자열 | `부분문자("hello", 1, 3)` -> "el" (끝 인덱스 미포함) |
| `정렬(배열)` | 배열 정렬 | `정렬([3,1,2])` -> [1,2,3] |
| `뒤집기(배열/문자열)` | 순서 뒤집기 | `뒤집기([1,2,3])` -> [3,2,1] |
| `찾기(배열, 값)` | 인덱스 반환 | `찾기([10,20], 20)` -> 1 |
| `조각(배열, 시작, 끝)` | 부분 배열 | `조각([1,2,3,4], 1, 3)` -> [2,3] |

| `걸러내기(배열, 함수)` | 배열 필터 (고차, `--eval`) | `걸러내기([1,-2,3], 양수)` -> [1,3] |
| `줄이기(배열, 함수, 초기값)` | 배열 축약 (고차, `--eval`) | `줄이기([1,2,3], 합, 0)` -> 6 |
| `JSON_파싱(문자열)` | JSON 파싱 | `JSON_파싱("[1, 2]")` -> [1, 2] |
| `JSON_직렬화(값)` | JSON 직렬화 | `JSON_직렬화({"a": 1})` -> "{\"a\":1}" |

## 바이트코드 VM

바이트코드 VM이 **기본 실행 백엔드**입니다. 트리워킹 인터프리터로 실행하려면 `--eval` 플래그를 사용합니다. `--vm` 플래그는 호환성을 위해 남아 있지만 아무 효과가 없습니다.

```bash
./cmake-build-debug/HongIk filename.hik          # VM (기본)
./cmake-build-debug/HongIk --eval filename.hik   # 트리워킹 인터프리터
```

VM은 소스코드를 바이트코드로 컴파일한 후 스택 기반 가상 머신에서 실행합니다. 기본 연산, 변수, 함수, 클래스, 예외 처리 등 대부분의 기능을 지원합니다. 고차 함수(`매핑`/`걸러내기`/`줄이기`)와 `부모` 호출은 현재 `--eval`에서만 동작합니다.

## 에디터 지원 (LSP)

`hongik-lsp`는 표준 입출력(stdio) 기반 JSON-RPC로 통신하는 Language Server입니다. 진단(문법/타입 에러), 호버, 자동완성, 정의로 이동, 문서 심볼(아웃라인)을 지원합니다.

### 빌드
```bash
cmake --build cmake-build-debug --target hongik-lsp
```

### VSCode 확장
```bash
cd vscode-extension
npm install
npm run compile
```

VSCode에서 `hongik.lsp.path` 설정에 빌드된 `hongik-lsp(.exe)`의 절대 경로를 지정하면 확장이 서버를 실행합니다. 비어 있으면 PATH에서 `hongik-lsp`를 찾습니다. 자세한 검증 절차는 [`vscode-extension/DEVELOPMENT.md`](./vscode-extension/DEVELOPMENT.md)를 참고하세요.

## 아키텍처

```
소스코드(한글) -> Lexer -> Parser -> Compiler -> VM -> 결과        (기본)
                  |         |          |          |
               Tokens     AST     Bytecode     Stack

             또는 (--eval)

소스코드(한글) -> Lexer -> Parser -> Evaluator -> 결과
                  |         |          |
               Tokens     AST    Environment
```
